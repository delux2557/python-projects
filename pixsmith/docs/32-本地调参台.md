# 本地调参台

> 对应版本：v0.7.0

## 一句话

```bash
pixsmith serve            # → http://127.0.0.1:8765/  自动开浏览器
```

浏览器里选图案、**拖滑块实时看效果**、调好之后**一键复制场景 JSON**。

## 它解决什么

在此之前，调一个图案的参数要：改代码 → 跑 → 打开文件看 → 再改。一轮十几秒，手感全丢。

调参台把这一圈压成"拖一下、立刻看到"。更关键的是**出口是场景 JSON**，不是一张图：

```
人：在调参台里拖着看，满意 → 复制 JSON
     ↓
机器：把这段 JSON 给 CLI / agent / 存进 git —— 一模一样地复现
```

所以它和 MCP 是互补的，不是重复的：

| | 服务对象 | 交互 |
|---|---|---|
| **MCP server**（`pixsmith-mcp`） | **agent** | 机器调用工具 |
| **本地调参台**（`pixsmith serve`） | **人** | 手工拖滑块 |

两边产出**同一个场景 JSON**，三条通道（CLI / MCP / 调参台）完全互通。

## ⭐ 控件是自动生成的

前端**不手写任何一个图案的控件** —— 全部从 `patterns` 里的 `Param` 声明现推：

| `Param.type` | 生成的控件 |
|---|---|
| `color` | 取色器 + 8 位 hex 文本框（取色器管不了 alpha，文本框补上） |
| `float` / `int` | 滑块 + 数字框（数字框是权威值，滑块只是够快） |
| `bool` | 复选开关 |
| `str` | 文本框 |
| `points` / `stops` | JSON 文本框（结构化值不该靠猜） |

**所以加一个图案，调参台自动就支持它** —— 不用动一行前端代码。

这是本项目一贯的"声明一次、多处消费"：`Param` 已经同时喂给了
CLI 校验、帮助文本、能力清单，**这里是第四个消费方**。

> 顺带一个诚实的限制：`Param` 目前没有 `min`/`max`，所以滑块的量程是从默认值
> 推断的（`0 … 3×默认`；默认是 0 则取 `-1 … 1`）。滑块是**便利**不是**约束** ——
> 想要精确值直接改数字框。给 `Param` 加边界声明是后续可以做的事。

## 页面有什么

- **左**：预览（棋盘格底，透明区一眼可辨）
- **左下**：自检报告（通道跨度 / 四角取样 / 主色覆盖率 / hints）+ **场景 JSON**
- **右**：图案选择（按分类分组，只支持位图的会标注）· 画布尺寸与底色 · 参数控件

渲染是**去抖 220ms** 的，拖动过程中不会把请求堆起来；只发送与默认值不同的参数。

## 安全：本地服务该有的三道

本地 HTTP 服务不是"没暴露在公网就安全"，它有三类真实攻击面：

| 措施 | 挡什么 |
|---|---|
| **默认只绑 `127.0.0.1`** | 不给局域网开门（要改需显式 `--host`，并会二次提醒） |
| **Host 白名单** | **DNS 重绑定** —— 攻击者把自己的域名解析到 127.0.0.1，浏览器就以为同源了 |
| **Origin 校验** | **跨站 CSRF** —— 别的网页偷偷 POST 到你的 localhost |
| 尺寸上限 4096px · 请求体上限 256KB | 拖一个大滑块 / 塞一个大 body 把机器卡住 |

## 零依赖

只用标准库 `http.server`。不需要 Flask、不需要 npm、不需要构建工具 ——
一份 Python 装好就能跑，跟这个项目的其余部分一个风格。

## 自己验证

```bash
pytest tests/test_playground.py      # 直接打真实 HTTP 端口，不 mock
```

测试起真服务器、打真端口：这层的风险几乎全在 HTTP 行为上（状态码、路由、
越界拒绝、头部校验），mock 掉 `BaseHTTPRequestHandler` 等于把要验的东西全绕过。

## 一个踩过的平台差异（写下来免得重踩）

Windows 上 `SO_REUSEADDR` **允许抢占已被监听的口**（Unix 上只用来跳过 TIME_WAIT，
不允许抢占）。所以端口探测如果照抄 Unix 写法，会把"已占用"误判成"空闲"，
结果两个服务器绑在同一个端口上。

正确做法：探测时在 Windows 用 `SO_EXCLUSIVEADDRUSE`，
并且注意到这个平台差异后把服务器的 `allow_reuse_address` 也一并关掉。
