# 能力边界（诚实版）

> 这份文档只回答一个问题：**什么情况下该用 pixsmith，什么情况下不该。**
> 提前把边界画清楚，比事后解释"为什么不行"便宜得多。
>
> **对应版本：v0.5.0** ｜ **权威能力清单以 `pixsmith spec --json` 为准** ——
> 那份清单是从代码里的声明**生成**的，不会过期；这份文档是人话版本，可能滞后。
> 有 `tests/test_docs.py` 守着版本号，改了能力忘了改文档会失败。

---

## 一、一句话判断

> 如果你要的是「**几十张风格一致、颜色要改、三个月后还要能复现**的底图」→ 用它。
> 如果你要的是「**一张好看的照片 / 插图 / 图标**」→ 别用它。

---

## 二、能做 / 不能做

| 维度 | ✅ 能做 | ❌ 做不到 |
|---|---|---|
| **几何图形** | 圆 / 环 / 椭圆 / 矩形（含圆角）/ 线段 / 弧 / 任意多边形 / 正 N 边形 / N 角星 / 抠洞 | 贝塞尔曲线编辑、布尔运算、路径描边（矢量后端可描边，位图不可） |
| **底纹** | 线性·径向渐变、条纹、棋盘、点阵、网格、同心环、均匀噪点、暗角 | 需要真实照片为源的纹理 |
| **程序化纹理** | **大理石 / 云 / 裂纹 / 拉丝金属**（噪声族：Perlin·Value·Cellular·fBm·域扭曲）、星空、半调网点、扫描线 | 写实木纹、编织物、真实材料扫描 |
| **符号** | 光芒阵列、齿轮、透视地板、星形、月亮、烟花、旗帜 | 具体品牌图标（去图标库） |
| **滤镜（一元算子）** | 高斯模糊（盒式×3 近似）、亮度/对比度/饱和度/色相/伽马、海报化、曝光、反相、去色、颗粒 | **中值 / 形态学 / 边缘检测 / 浮雕 / 自定义卷积核**（这些 Pillow 有，本项目没有） |
| **合成（二元算子）** | **14 种混合模式**（multiply / screen / overlay / soft-light / hard-light / difference / dodge / burn …）、图层不透明度 | 分组预合成隔离、蒙版图层、调整图层（live effect） |
| **输出** | **PNG**（8 位 RGBA、任意尺寸、透明通道）与 **SVG**（矢量、可无损缩放、PPT 原生支持） | PDF / EPS / CMYK / 印刷色彩管理 / EXIF；**SVG → PNG 栅格化**（请用 resvg / cairosvg） |
| **文字** | 不能画文字（用 HTML / PPT / 排版软件去排） | 任何字体渲染、文字阴影 |
| **变换** | 单个图元可带角度（椭圆 / 星形 / 直线） | **整幅图的旋转 / 缩放 / 裁剪 / 透视变换**（没有仿射变换算子） |
| **交互** | 静态图 | 动画 / 视频 / Lottie |
| **接入方式** | CLI · Python API · **MCP server**（agent 调用）· **本地调参台**（人用） | 设计软件插件 |

## 三、双后端能力对照（v0.2 起）

| | 位图 `Canvas` | 矢量 `SvgBackend` |
|---|---|---|
| 输出 | PNG | SVG |
| 强项 | 逐像素纹理、噪点、非线性滤镜、模糊 | 无损缩放、体积小、可编辑、PPT 友好 |
| 图案支持 | **23 / 23** | **15 / 23** |
| 一元算子 | 全部（含 `grain`） | blur / adjust / posterize / solarize / invert / grayscale |
| 逐像素场 | ✅ | ❌ 矢量域没有对应物 |

矢量后端不支持的 8 个图案全是**逐像素场**：`stripes` `checker` `noise` `vignette`
`marble` `clouds` `cracks` `brushed`（`starfield` 只在开了银河带时才需要位图）。
**后端缺能力会报错并给出替代方案，不会静默降级** —— 因为静默降级会产出"看着对但缺了效果"的图。

## 四、与其它方案的分工

| 需求 | 该用什么 | 为什么不用 pixsmith |
|---|---|---|
| 一张好看的风景照片 | 图库（Unsplash / Pexels）、AI 生图 | pixsmith 只会画图元与场，画不出照片 |
| 一个扁平风格图标 | 图标库（iconfont / FontAwesome / Lucide） | 图标库有几千个现成的，别自己画 |
| 需要"按描述生成任意画面" | AI 生图 | 那是生成模型的领域 |
| **矢量图形 / 需要无损放大** | **pixsmith 的 SVG 后端** | — |
| 需要**文字排版** | `drawsvg` / `pycairo` / SVG 文本 / PPT | 本项目不碰字体光栅化（那会带来字体依赖） |
| 需要**中值 / 边缘检测 / 浮雕 / 自定义卷积** | Pillow（`ImageFilter`） | 本项目的滤镜族刻意只做常见的那几种 |
| 需要把图**处理**（裁剪已有照片 / 合成多张照片） | Pillow / ImageMagick | pixsmith 是**生成器**，不是处理器 |
| 需要 20 张**只有主色不同**的底图 | **pixsmith** | 图库要挑 20 次，AI 生图 20 次结果不一致 |
| 需要精确复现三个月前的底图 | **pixsmith** | 图库链接会失效，AI 生图不可复现 |

## 五、技术限制（都是实测过的）

| 限制 | 影响 | 说明 |
|---|---|---|
| 图元代价 = **包围盒面积** | 长线段 / 大多边形在大画布上慢 | 已做分块 + 向量化，但代价模型没变。2560×1440 上 46 条 1300px 射线 ≈ 0.15 s |
| 小图元有**每次调用开销** | 星星、点阵这类"大量小图元"提速有限（约 6×） | 420 颗星的星场仍在 10 ms 量级，可接受 |
| 模糊是**盒式×3 近似**高斯 | 不是精确高斯核；大半径下与真高斯有细微差异 | 换来的是 O(n)：半径 200 在 1920×1080 上仍是亚秒级。要精确高斯用 Pillow |
| 抗锯齿是**覆盖率**而非超采样降噪 | 极细的线段（< 1px）会偏淡 | 需要极细线时把宽度提到 ≥ 1.5px |
| 没有**仿射变换算子** | 不能旋转/缩放/裁剪整幅已绘内容 | 只有图元自带的 `ang` 参数；整幅变换目前要位图后端自己拼 |
| 没有**景深 / 散景** | 真实光学虚化做不出来 | 模糊可以，但"漂亮的光斑"需要卷积核，本项目不提供 |
| 依赖 `numpy` | 不是零依赖 | 若要零依赖，用 `benchmarks/pure_python_reference.py`（慢 6–42×） |

## 六、确定性的边界

「同 seed 同字节」这条承诺**有前提**：

- ✅ 同一台机器、同一个 numpy 版本、同参数 → 逐字节一致（有测试守着）。
- ⚠️ **跨 numpy 大版本**不保证逐字节一致（浮点累加顺序、`default_rng` 的位流在不同主版本间
  可能变化）。跨版本复现请连 numpy 版本一起锁住。
- ⚠️ 跨平台（x86/ARM 的 SIMD 路径差异）同理。像素级复现需求请在同架构上产出并入库。

> 实践建议：**把生成的产物一起提交进 git**。像素级复现是为了"能重新生成"，
> 而最稳的"能重新生成"就是把产物本身存下来 —— 两者都要，别只靠后者。

## 七、还没做（可能值得做）

| 想法 | 价值 | 成本 |
|---|---|---|
| **仿射变换算子**（整幅旋转 / 缩放 / 裁剪） | 中 —— 现在是个真实缺口 | 中 |
| 卷积核族（自定义 kernel / 中值 / 边缘 / 浮雕） | 中 —— 让滤镜族追上 Pillow | 中 |
| 分组预合成（`group` + blend 隔离） | 中 —— 复杂合成才需要 | 中 |
| 更多节日符号（春节 / 端午 / 圣诞） | 低-中 | 低（有 `festive.py` 的范式） |
| PyPI 发布 | 中 —— 让人 `pip install pixsmith` | 低 |
| 纯 Python 后端自动降级（没装 numpy 也能跑） | 低 | 中（要保证两条路径逐字节一致） |

## 八、如果它让你失望了

大概率是这两种情况之一：

1. **你想要"素材"，而它是一个"生成器"。** → 去看图库或 AI 生图。
2. **你想要"设计感"，而它只能保证"参数化"。** → 好看与否仍取决于你给的配色和构图；
   它能保证的是**这套好看的参数能一模一样地再用一次**。

这两种失望都很合理。写在这里，是为了让你在花时间之前就知道。
