# 能力边界（诚实版）

> 这份文档只回答一个问题：**什么情况下该用 pixsmith，什么情况下不该。**
> 提前把边界画清楚，比事后解释"为什么不行"便宜得多。

---

## 一、一句话判断

> 如果你要的是「**几十张风格一致、颜色要改、三个月后还要能复现**的底图」→ 用它。
> 如果你要的是「**一张好看的照片 / 插图 / 图标**」→ 别用它。

---

## 二、能做 / 不能做

| 维度 | ✅ 能做（而且往往比图库更好） | ❌ 做不到 |
|---|---|---|
| **内容** | 渐变、条纹、棋盘、点阵、网格、噪点、星空、半调网点、扫描线、光芒、齿轮、透视地板、星形、月亮、烟花 | 人物、建筑照片、真实材质（木纹/大理石/金属）、复杂插画 |
| **风格** | 抽象 / 几何 / 科技感 / 扁平 / 暗光影调 | 写实、手绘、水彩、3D 渲染 |
| **精度** | 可以精确到像素与角度（如国旗的星位与指向角有国标） | 需要"恰到好处的不完美"的艺术判断 |
| **输出** | PNG（8 位 RGBA）、任意尺寸、透明通道 | SVG / PDF / 矢量、CMYK、印刷色彩管理、EXIF |
| **文字** | 不能画文字（用 HTML / PPT / 排版软件去排） | 任何字体渲染、文字阴影 |
| **交互** | 静态图 | 动画 / 视频 / Lottie |

---

## 三、与其它方案的分工

| 需求 | 该用什么 | 为什么不用 pixsmith |
|---|---|---|
| 一张好看的风景照片 | 图库（Unsplash / Pexels）、AI 生图 | pixsmith 只会画图元，画不出照片 |
| 一个扁平风格图标 | 图标库（iconfont / FontAwesome / Lucide） | 图标库有几千个现成的，别自己画 |
| 需要"按需求描述生成任意画面" | AI 生图 | 那是生成模型的领域 |
| 需要 20 张**只有主色不同**的底图 | **pixsmith** | 图库要挑 20 次，AI 生图 20 次结果不一致 |
| 需要精确复现三个月前的底图 | **pixsmith** | 图库链接会失效，AI 生图不可复现 |
| 需要矢量、需要文字排版 | `drawsvg` / `pycairo` / Pillow | 本项目的定位就是"低分辨率位图 + 图元" |
| 需要把图**处理**（裁剪/滤镜/合成已有照片） | Pillow / ImageMagick | pixsmith 是生成器，不是处理器（`colorFilter` 只作用于自己生成的图） |

## 四、技术限制（都是实测过的）

| 限制 | 影响 | 说明 |
|---|---|---|
| 图元代价 = **包围盒面积** | 长线段 / 大多边形在大画布上慢 | pixsmith 已做分块 + 向量化，但代价模型没变。2560×1440 上 46 条 1300px 射线 ≈ 0.15 s |
| 小图元有**每次调用开销** | 星星、点阵这类"大量小图元"提速有限（约 6×） | 420 颗星的星场仍在 10 ms 量级，可接受 |
| 抗锯齿是**覆盖率**而非超采样降噪 | 极细的线段（< 1px）会偏淡 | 需要极细线时把宽度提到 ≥ 1.5px |
| 只有 **straight alpha**，没有真正的混合模式 | 不能做 multiply / screen 之类的 PS 混合 | `erase_disc` 提供 dst-out（抠洞），其余靠"叠加 + 透明度"模拟 |
| 没有模糊 / 卷积 | 做不出真实景深与柔和辉光 | 用"多层递减透明度的圆"近似（见 `examples/03_custom_primitive.py`） |
| 依赖 `numpy` | 不是零依赖 | 若要零依赖，用 `benchmarks/pure_python_reference.py`（慢 6–42×） |

## 五、确定性的边界

「同 seed 同字节」这条承诺**有前提**：

- ✅ 同一台机器、同一个 numpy 版本、同参数 → 逐字节一致（有测试守着）。
- ⚠️ **跨 numpy 大版本**不保证逐字节一致（浮点累加顺序、`default_rng` 的位流在不同主版本间
  可能变化）。跨版本复现请连 numpy 版本一起锁住。
- ⚠️ 跨平台（x86/ARM 的 SIMD 路径差异）同理。像素级复现需求请在同架构上产出并入库。

> 实践建议：**把生成的 PNG 一起提交进 git**。像素级复现是为了"能重新生成"，
> 而最稳的"能重新生成"就是把产物本身存下来 —— 两者都要，别只靠后者。

## 六、还没做（可能值得做）

| 想法 | 价值 | 成本 |
|---|---|---|
| **单 HTML 调参台**（canvas 实时预览 + 一键复制配方） | 高 —— 让非程序员也能用 | 中（一份零依赖 HTML） |
| 纯 Python 后端自动降级（没装 numpy 也能跑） | 中 —— 摘掉硬依赖 | 中（需要保证两条路径逐字节一致） |
| SVG 输出 | 中 —— 需要矢量时 | 高（图元语义要重写） |
| 模糊 / 高斯 / 卷积 | 中 —— 辉光更自然 | 中 |
| 更多节日符号（春节 / 端午 / 圣诞） | 低-中 | 低（有 `festive.py` 的范式） |
| PyPI 发布 + CI 矩阵 | 高 —— 让人`pip install pixsmith` | 低 |

---

## 七、如果它让你失望了

大概率是这两种情况之一：

1. **你想要"素材"，而它是一个"生成器"。** → 去看图库或 AI 生图。
2. **你想要"设计感"，而它只能保证"参数化"。** → 好看与否仍取决于你给的配色和构图；
   它能保证的是**这套好看的参数能一模一样地再用一次**。

这两种失望都很合理。写在这里，是为了让你在花时间之前就知道。
