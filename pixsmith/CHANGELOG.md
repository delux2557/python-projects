## 0.3.0 — 贡献机制（2026-09-14）

主题：**让"别人也能加素材"从口号变成可操作**。

### 新增
- **`pixsmith new <key>` 脚手架**：一条命令生成图案骨架（含参数声明、双后端声明提示、
  收录三问模板），`-o` 可直接落盘；重名给出警告，非法名直接拒绝。
- **`CONTRIBUTING.md`**：分两档门槛 —— 素材层欢迎天天加，能力层先开 issue 对齐。
  含**收录标准**（三问 + 查重 + 命名 + 种子要求）、**双后端贡献注意事项**、
  提交前自检清单，以及**「文字与命名禁忌」**（把"不带来源叙事、不出现厂商字样"
  固化成可执行的检查项）。
- 仓库根目录补 **`LICENSE`**（MIT）—— 之前只在 `pixsmith/` 内有，GitHub 不识别。

### 调整
- 术语统一：**JSON 快捷通道 ｜ Python 创作通道**。原措辞的中文语感偏消极，
  等于把 Python 接口说成了降级方案；换成"创作通道"后两条通道都回到正向表述。
  README 新增「两条通道」一节，说明两者的取舍与选择方法。
- `.gitignore` 加入 `.workbuddy/`（agent 工作笔记，绝不发布）。

### 测试
283 → **287** 个用例（新增 4 个覆盖 `new` 子命令：骨架可用性、写文件、非法名、重名警告）。

## 0.2.0 — 双后端 + 元能力（2026-09-14）

主题：**从"图案库"升级为"能力层 + 素材层 + 后端可替换"**。

### 新增：矢量后端（`svg.py`）
- `SvgBackend` 与 `Canvas` **接口对齐**，同一份场景可输出 PNG 或 SVG
  （PPT 自 2016 原生支持 SVG —— 这是"双后端"对汇报场景的直接价值）。
- 机制：一元算子 = 把已累积内容包进 `<g filter="...">`；`erase_disc` = 用 `<mask>` 抠洞。
- **23 个图案中 15 个双后端通用**；其余 8 个显式声明 `requires=("paint",)`。

### 新增：元能力（一元 / 二元算子）
- **一元算子**（`filters.py`）：`blur`（盒式×3 近似高斯，**alpha 感知**，前缀和 O(n)）、
  `adjust`（亮度/对比度/饱和度/色相/伽马，矩阵照抄 SVG 规范）、`posterize`、`solarize`、
  `invert`、`grayscale`、`grain`（带 seed，可复现）。
- **二元算子**（`blend.py`）：14 种混合模式，公式遵循 **CSS Compositing / PDF 混合模型**，
  结果与浏览器 `mix-blend-mode` 一致（这样两个后端才可能真正对齐）。
- **噪声族**（`noise.py`）：Perlin / Value / Cellular(Worley) / fBm / 域扭曲，全部 NumPy 向量化。
- 4 个自然材质图案：`marble` `clouds` `cracks` `brushed`。

### 新增：场景 DSL（`scene.py` / `ops.py`）
- `Scene` = 尺寸 + 底色 + 图层（每层带 `blend` / `opacity`）；op 参数**扁平**
  （`{"op":"blur","radius":12}`，比 `{"op":...,"args":{...}}` 省 token）。
- 三种语法糖：顶层 `ops`（单层）、裸数组（一层）、顶层 `pattern`（等价旧配方）。
- **构造即校验**：未知动词/图案/键在 `from_dict` 阶段就报错，不留到渲染时。

### 新增：面向 agent 的接口
- `pixsmith spec [--json]`：能力清单（参数类型/默认值/后端支持/最小可用场景）。
- `pixsmith render --report`：自检报告（非透明占比 / 内容包围盒 / 主色 / 亮度 / 对比度）
  —— **agent 看不见图，靠它判断"画对没画对"**。
- **拒绝静默降级**：后端缺能力就报错并给替代方案。

### 架构调整
- 拆出 `backend.py`（后端协议 + 能力校验）、`geometry.py`（几何与渲染分离）、
  `field.py`（参数场）、`params.py`（参数声明公共契约）—— 依赖方向收敛为单向。
- `recipes.render()` 改为走 `Scene`：单图案与多图层不再有两套渲染路径。
- `pattern()` 声明新增 `requires` / `requires_fn`（**参数相关的动态依赖**）。

### 修复
- `fbm` 曾在**每个倍频后各自归一化**再叠加，导致 `persistence=0.5` 时**加倍频反而细节变少**
  （实测相邻差 0.0102 → 0.0084）。改为在原始域叠加、最后只归一化一次。
- 包级导出的 `blend` 函数会**遮蔽同名的 `blend` 子模块**（`from pixsmith import blend`
  拿到函数而非模块）。已改为只导出 `MODES` / `blend_names`。
- 图案里用 `hline`/`vline`（不在后端协议里）会挡住矢量后端；已改为协议方法 `capsule`。
- 契约测试抓出 `SvgBackend` 缺 `w`/`h` 属性 —— 双后端的代价应由后端承担，不该外溢到图案层。

### 测试
- 166 → **283** 个用例。新增：双后端契约、算子数学（含"模糊不渗黑边"）、噪声性质。

## 0.1.0 — 首个版本（2026-09-14）

首个公开版本：把一套用来程序化产出视觉元素的图形代码，做成通用库。

### 新增

- **画布** `Canvas`：8 个图元（`disc` / `ring` / `ellipse` / `rect` / `capsule` / `arc` /
  `polygon` / `erase_disc`），覆盖率抗锯齿（`feather` 与 `ss` 可调），直通道 Alpha 合成。
- **PNG 编码**：标准库 `zlib` + `struct`，无图像库；8 位 RGBA、filter 0、可复现的压缩级别。
- **19 个图案**，分 4 类：`background`(9) · `texture`(3) · `shape`(4) · `festive`(3)。
- **配方（recipe）**：JSON 声明式绘图指令，参数可覆盖、可校验、可回放。
- **CLI** `pixsmith`：`list` / `show` / `render` / `gallery`。
- **测试 166 个**，含与纯 Python 参考实现的**逐像素等价性**校验，
  以及五星红旗的**国标符合性**校验（从像素反测 GB 12982 的星位与指向角）。
- **性能基准** `benchmarks/bench.py`：与纯 Python 参考实现的同工作量对比。

### 相对逐像素原型的改进

- **性能**：逐像素 → NumPy 向量化。实测提升 **6×–42×**（随图元面积增长）。
- **修 bug**：`ring()` 的内边缘羽化。原实现未归一化外圈覆盖率就乘 `(1 - ci)`，
  被截断后内边缘变成硬边（最大差 156/255）。已修正并钉成回归测试。
- **修 bug**：长线段分块合成。分块后重叠带会被合成两次，半透明色会出现一条偏色带。
  改为按参数 `t` 把像素判给唯一分块。
- **去重**：原先散落着 3 份逐像素实现拷贝、`art_stars` 有 3 个版本。现统一到
  `canvas.py` + `patterns/`，参考实现只保留一份用于对照。
- **参数声明化**：图案参数从散落的函数默认值，改为 `Param` 声明
  （类型 / 默认值 / 说明），CLI 帮助与校验都从它生成。
