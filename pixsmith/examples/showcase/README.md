# 演示参考物：标识候选 + 主题图标

这里是两份**成规模**的生成脚本，用来演示 `pixsmith` 在"图标 / 标识"这类活上的实际用法。
它们不是教学示例（教学示例见上一级目录的 `01`–`04`），而是**可以照着改的参考物**：
每份都能一次产出几十张互换配色 / 尺寸的成品。

```bash
python examples/showcase/make_logos.py    # 5 个标识方案 × 尺寸阶梯 × 双单色墨
python examples/showcase/make_themes.py   # 21 个主题图标（电子制造 / 天气 / 节气 / IT 元素）
```

两份脚本都自带 `sys.path` 引导，**不装包也能直接跑**。
产物写在 `output/showcase/`（仓库约定：`output/` 是随手产物、不入库）；
挑中的作品再复制进 `gallery/` 提交即可。

---

## 一、这两份参考物演示了什么

| 脚本 | 演示的能力组合 |
|---|---|
| `make_logos.py` | 同一份几何按尺寸重算 → 产出 512/64/32/16 四个尺寸；颜色按"深墨/白墨"两种单色墨各出一版；坐标全部用 0–1 比例，所以**同一段代码**能出任意尺寸 |
| `make_themes.py` | 21 个图标全部由协议图元拼出，**每一个都能导出 SVG**；同时输出 PNG + SVG + 配方 JSON 三件套 |

## 二、四条设计约束（都是踩出来的，不是猜的）

### 1️⃣ 只用协议图元 → 才能出矢量

图案要当**图标**用，矢量能力比纹理质感更重要。所以这两份脚本里的所有形状都只用
`disc / ring / rect / ellipse / capsule / arc / polygon / line / star / regular_polygon / erase_disc`，
以及本身支持矢量的图案（`gradient / dots / grid / rings / gear / ray_burst` 等）。

`clouds / marble / noise / vignette / brushed / cracks` 这类"逐像素场"只支持位图后端 ——
一旦用了，这个图标就没法导出 SVG，也就没法拖进 PPT 或矢量软件无损放大。

> 怎么确认某个图案能不能出矢量：`pixsmith spec --json --only <key>`，看 `backend.svg`。
> 不要靠试错。

### 2️⃣ 形状之间不重叠（靠透明间隙分隔）→ 单色版才成立

彩色版里相邻的两个形状，压成单色后就粘成一团 —— 而单色版恰恰是标识最常见的用法
（印在任意底色上、刻字、传真、单色印刷）。

这一条在 `make_logos.py` 里被**实测抓到过两次**：
齿轮方案的折线与柱子挤在同一片区域、字母 A 的柱子压在 A 的右腿肉身上 ——
彩色版靠金/青绿分得开，单色版直接糊成一块。修法是让它们**分层不重叠**，
而不是把颜色调开。

### 3️⃣ 两种单色墨，不是一种

单色标识的标准用法就是**浅底用深墨、深底用白墨**。
只出深墨版等于漏了一半 —— 深墨压在深底上就是没画。所以每个方案都有
`_mono_512.png`（深墨）与 `_mono_light_512.png`（白墨）两版。

### 4️⃣ 小尺寸主动降级，而不是硬缩

`make_logos.py` 里的 `small(s)` 在 `s <= 64` 时**主动丢掉亚像素级细节**
（细线换成胶囊拼边、细环换成实心点）。理由：16px 下 0.014 宽的线只有 0.22px——
渲染出来是一条几乎透明的灰线，与其让它糊在那儿，不如按尺寸换成"少而粗"的版本。
这是专业标识的标准做法。

## 三、怎么判断"缩到 16px 还认不认得"

不靠肉眼，也不靠"负空间占比"这类直觉指标（它在小尺寸下会因为栅格化把亚像素形状补胖而**反向**上升，
数值越"健康"实际越糊）。可用的判据是 **IoU 对缩放**：

> 把 512px 按**面积平均**（不是最近邻，最近邻会漏掉细线）缩到目标尺寸当参考掩膜，
> 再和原生渲染的小尺寸比 IoU。IoU 高 = 小尺寸长出来的样子和大图缩下来的一致 = 结构没丢。

加了小尺寸简化变体的方案**不能**再用这把尺子量（它本来就该和缩放结果不一样）——
变体单独看"覆盖率落在 8%–60%"与"封闭孔洞数 ≥ 1"。

另外还有一条更朴素的：**把 N 个变体拼成一张联络表，看一眼**。
数值只能验证你想到要测的东西，眼睛能发现你没想到的 ——
这两份脚本里的形状相交问题，全都是拼图看出来的。
